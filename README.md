# Лабораторна №6 — SVG, варіант 5

Відкрийте `svg.html` у браузері. Для локального сервера: `python3 -m http.server 8065`.

Додано статичний малюнок варіанта 5, текст по кривій та п’ять SMIL-ефектів: колір, translate, rotate, scale, skewX. Кнопки «Пауза» і «Спочатку» керують анімацією. Режим зменшення руху призупиняє її на початку.

Зовнішні SVG підключені через object, embed та iframe. Тег param наведено як застарілу вимогу методички; параметр не керує SVG. Коректні SVG-теги: symbol, textPath, animateTransform.

Сторінки лабораторної №5 збережені, у навігації є пункт SVG. Текстові джерела графіки — `assets/svg/`. Для повторного складання: `python3 scripts/build_svgs.py`; шаблон сторінки — `scripts/svg-page.template.html`.

Звіт: `report/lab6-svg-variant5.pdf`. Пам’ятка до захисту: `report/Захист.md`.
